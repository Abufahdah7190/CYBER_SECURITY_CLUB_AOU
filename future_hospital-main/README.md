# مستشفى المستقبل — موقع افتراضي

ملفات المشروع:
- `index.html` — الصفحة الرئيسية (RTL، عربي)
- `css/style.css` — تنسيقات وواجهات
- `js/main.js` — تفاعلات بسيطة وحجز مواعيد (عميل فقط)
- `assets/` — شعارات وصور SVG

تشغيل محلي:
1. افتح الملف `index.html` في متصفحك (نقرة مزدوجة أو سحب إلى نافذة المتصفح).
2. للحصول على تجربة أفضل على هاتف، خزن الملفات على خادم محلي مثل Live Server أو افتح عبر VS Code Live Server.

هل تريد أن أضيف صفحات داخلية (تفاصيل كل قسم، صفحة حالة المريض، تسجيل دخول) أو أعدّ لك إصدارًا جاهزًا للنشر؟
